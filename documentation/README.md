# Organized Week Docs

Documentación oficial en español de Organized Week, construida con Docusaurus
3.10.2.

## Desarrollo local

```bash
npm install
npm run start
```

## Compilación

```bash
npm run build
npm run serve
```

La documentación describe la aplicación principal sin añadir autenticación,
backend, API, sincronización entre dispositivos ni almacenamiento remoto.
