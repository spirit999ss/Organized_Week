# Tareas semanales

El panel **Tareas del día** mantiene una lista independiente para cada fecha.
Selecciona un día y escribe el texto de una nueva tarea para añadirla.

## Acciones disponibles

- Añadir una tarea con texto no vacío.
- Marcarla como realizada o volver a dejarla pendiente.
- Editar el texto.
- Eliminar una tarea.
- Limpiar todas las tareas del día seleccionado, después de confirmar.

El contador del panel muestra cuántas tareas están realizadas. Las tareas no
afectan al progreso de hábitos ni generan minutos de premio.

## Fechas y semana

Cada registro se guarda con una fecha ISO (`AAAA-MM-DD`). Cambiar de día solo
cambia la lista visible; no elimina las tareas de los demás días.

Las tareas se normalizan al cargar datos compatibles guardados con nombres de
días anteriores. Los elementos con estructura inválida no se incorporan a la
lista visible.
