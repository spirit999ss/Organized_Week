# Hábitos y progreso

Los hábitos se definen una vez y luego se marcan por fecha. El panel muestra
cuántos hábitos están completados y el porcentaje del día.

## Gestionar hábitos

Desde el gestor de hábitos puedes:

- Crear un hábito con un nombre.
- Editar su nombre.
- Eliminarlo.

Al eliminar una definición también se limpia su referencia del progreso y se
recalculan las recompensas.

## Reglas del progreso

- El progreso se registra de lunes a sábado.
- El domingo no suma hábitos.
- Cada identificador se cuenta una sola vez.
- Solo se conservan identificadores que todavía correspondan a hábitos
  definidos.
- Completar todos los hábitos definidos en un día válido marca ese día como
  recompensado.

Si no hay hábitos definidos, el porcentaje es 0 y no se genera recompensa.
El resumen semanal usa las mismas reglas que el panel diario.
