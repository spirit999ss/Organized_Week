# Privacidad y conservación de datos

La aplicación no incluye autenticación, cuentas, backend, API ni sincronización
entre dispositivos. Las tareas, hábitos, premios, metas y referencias se
conservan en el almacenamiento local del navegador; las imágenes se conservan
en IndexedDB.

Esto significa que los datos permanecen en el dispositivo y navegador donde se
utiliza Organized Week. No se envían a la nube desde la aplicación.

## Consecuencias prácticas

- Usar otro navegador o dispositivo no muestra los mismos datos.
- Borrar los datos del sitio puede hacer que la información deje de estar
  disponible.
- La aplicación no implementa copias de seguridad ni restauración.
- La disponibilidad depende de la cuota y de las decisiones del navegador.

Si necesitas conservar una instalación, evita limpiar los datos del sitio de
ese navegador. La documentación no describe una exportación porque la
aplicación no implementa esa función.
