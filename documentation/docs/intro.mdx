# Organized Week

Organized Week es un planificador semanal personal que reúne tareas, hábitos,
recompensas y metas visuales en una sola interfaz. Funciona completamente en el
navegador: no requiere cuentas, backend ni conexión con una base de datos
remota.

## Cómo se organiza una semana

La aplicación permite seleccionar cualquiera de los siete días, desde domingo
hasta sábado. El día seleccionado determina las tareas y el progreso que se
muestran. Las tareas pertenecen a una fecha concreta; los hábitos se registran
por fecha y sus recompensas se recalculan a partir de ese progreso.

El domingo tiene un comportamiento especial: no registra progreso de hábitos y
es el día en que se pueden consumir los minutos de premio acumulados.

## Recorrido recomendado

1. Define tus hábitos y tareas de cada día.
2. Marca los hábitos completados de lunes a sábado.
3. Revisa el resumen semanal y las horas acumuladas.
4. Configura opciones de premio y registra consumos el domingo.
5. Añade metas al Vision Board y actualiza su estado.
