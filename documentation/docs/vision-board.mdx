# Vision Board

El Vision Board representa metas personales como tarjetas. Cada meta tiene
título, descripción, estado, fechas de creación y actualización y una imagen
opcional.

## Crear y editar metas

Puedes crear una meta con título obligatorio y descripción opcional. En cada
tarjeta puedes editar el texto, cambiar el estado o eliminar la meta.

Los estados disponibles son:

- `pendiente`
- `en progreso`
- `conseguida`

El tablero admite como máximo **9 metas**. Al alcanzar el límite, primero debes
eliminar una para crear otra.

## Imágenes

Las imágenes se gestionan por separado del texto de la meta. Puedes añadir una
al crearla, cambiarla o quitarla sin eliminar la meta. Consulta [Gestión de
imágenes del Vision Board](./imagenes-vision-board) para los formatos y el
almacenamiento.
